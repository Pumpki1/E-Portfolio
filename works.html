Dog Emotion Recognition

A deep learning study that classifies the emotional state of dogs from images into four categories, which are happy, sad, angry, and relaxed, in support of automated animal health monitoring. The project compares a custom convolutional neural network against a MobileNetV2 transfer learning model, both trained on the same balanced dataset of 800 labeled images prepared through resizing, normalization, and data augmentation. The transfer learning model reached 80% accuracy on unseen test data, compared with 26.1% for the custom network, which shows the advantage of pre-trained features on small datasets.

AI Based Air Monitoring System

An Arduino based indoor air quality monitor that responds to hazards instead of only reporting them. Four gas sensors covering smoke and flammable gases, alcohol and chemical vapors, carbon monoxide, and general air quality feed an adaptive model that learns the normal air baseline during a five minute training period and stores it in EEPROM. Filtered readings are then checked for anomalies using Z-score and median absolute deviation analysis, graded across four warning levels shown through LED indicators, an I2C display, and a buzzer. A dangerous level automatically switches on an exhaust fan, and a retrain button allows the system to recalibrate to a new environment.

Role
Lead Developer, Embedded Systems Developer, IoT Developer
Software and Tools
Arduino IDE, Arduino C++
Libraries and Frameworks
Wire, LiquidCrystal_I2C, EEPROM

CPU Escape Box

An interactive mini arcade system that teaches computer architecture through gameplay. Players trace register level instructions across Easy, Medium, and Hard levels within a five minute countdown, using a joystick and push buttons on a 2.8 inch display. The system includes user registration and profile management with create, read, update, and delete functions, a Top 20 leaderboard, and persistent storage in the Arduino EEPROM. Completing every level in time energizes a solenoid lock that opens a reward compartment, and the electronics are housed in a cyber themed arcade cabinet.

Laboratory Access through Face Detection

A face recognition access control system for laboratory rooms, designed to replace manual logbooks and physical keys with automated identification. A Raspberry Pi enhances each camera frame through a digital signal processing chain of bilateral filtering, adaptive histogram equalization, and sharpening, detects faces with a Haar cascade, and matches them against registered users using deep learning face embeddings. A recognized person receives an Access Granted message on an LCD and a buzzer confirmation while a servo motor opens the door, and unrecognized faces are denied with a short retry delay. Every access attempt is recorded in a Supabase database.

Lead Developer, Embedded Systems Developer, Computer Vision Developer
